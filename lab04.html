Introduction to Web Technology

Every website you have ever scrolled through is built on three things: HTML for the structure, CSS for the looks, and JavaScript for the behaviour. Think of a house. HTML is the walls and the rooms, CSS is the paint and the furniture, and JavaScript is the electricity that makes the lights turn on.

The browser downloads these files from a web server (in my case, GitHub Pages) and puts the whole thing together on your screen in a fraction of a second.

So What Is CSS?

CSS stands for Cascading Style Sheets. It tells the browser how each element should look: colours, fonts, sizes, spacing and borders. The "cascading" part means that when two rules fight over the same element, the more specific one wins. My h1 rule says purple, my * rule says dark slate grey, and the heading at the top of this page is still purple.

All the styling on this page lives in one external file, styles/lab04.css, linked from the <head>. One file, one link, and the whole page changes.

Headings and Paragraphs

Headings and paragraphs are block elements. They take up the whole width of the page and refuse to share a line with anyone, like that one person who sits in the middle of the bus seat.

Headings

HTML gives us six levels of headings, from h1 down to h6. Use them in order, like chapters in a book. If a heading looks too big, don't swap it for a smaller level. Change its size in the CSS instead. Headings describe structure, CSS handles the looks.

Paragraphs

Paragraphs hold the actual reading material of a page, like what you are reading right now. One rule to remember: you can't put another block element (like a heading or a list) inside a paragraph. Paragraphs don't share their space.

Special Characters

HTML knows lots of named special characters, like the registered sign ® (#174). XML is pickier and only accepts five by name: " ' & < and >. To stay on everyone's good side, use the number codes for everything else.
